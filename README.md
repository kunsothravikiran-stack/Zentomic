# Zentomic

Modern business IVR and AI call routing, intended for Python AWS Lambda,
API Gateway, DynamoDB, Twilio, and OpenAI.

This repository is a new development starting point, not an export of the
production service. Development starts with offline, dependency-free Python
components and synthetic test fixtures.

Do not commit credentials, account identifiers, real phone numbers, call
transcripts, or customer data. No deployment workflows, paid API calls, real
calls, or messages are included.
